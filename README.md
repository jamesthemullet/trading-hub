# Your APP repository for using brightcloud

![brightcloud](https://img.shields.io/badge/powered--by-brightcloud-blue)

This repository will bootstrap the repository that created from this template with the following configuration

#### Workflows
- repo-init: This is a workflow for bootstrapping brightcloud onto the repository created from this template
- cloud9-devsecops-cicd-pipeline: This is a workflow for bootstrapping application build and deploy starter workflow in the repository based on the stack configuration
- dependabot: [Dependabot](https://docs.github.com/en/code-security/dependabot/dependabot-version-updates/configuration-options-for-the-dependabot.yml-file) workflow for upgrading dependencies in the repository relevant to the stack
- probot: [probot](https://probot.github.io/apps/settings/) settings to manage the repository settings as configuration than manual

Alternatively, if you are not creating a repository from this template, you could also copy the relevant workflow yaml files into the target repository.
